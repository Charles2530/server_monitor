# 非终端页面优化实施计划

> 按 subagent-driven-development 执行独立模块并进行需求与代码复核。用户已确认审查方案，全部修改直接在 main 工作区实施，不建分支，不覆盖既有改动。

**目标**：完成非终端页面审查中的缺陷修复、手机与阅读体验改善，以及有证据支持的性能优化。

**结构**：沿用原生 JS 模块及 FastAPI manager。公共导航和轻量 DOM 行复用放在现有 navigation.js；使用现有 mobile.css、visual-refresh.css 的变量与继承。无需新生产模块或依赖。

**技术**：Python/FastAPI、原生 JS、CSS、Playwright、pytest、node:test。

基线备份为 `data/nonterminal-before-1011-1138`，包含开始修改前的产品源码及 SHA-256 清单。验证使用隔离模拟 API。

## 1. 数据行为

- [ ] TokenHub：新日期请求取消旧请求；列表按 ID 复用；保留正在复制的按钮；账户/分组变化使缓存失效；短期复用趋势与列表；可见时合并图表 resize。
- [ ] ACP：预览绑定页面 generation，切页后忽略响应；配置刷新沿用 options 函数并保留用户输入。
- [ ] 存储/历史/队列：前端显式手动调用 `refresh(true)`，GET 加 `refresh=true`；后端 `snapshot(force=False)` 在原有 singleflight 约束内绕过 TTL，存储同时刷新挂载。
- [ ] 总览：渲染签名包含指标是否过期；运行任务/队列保留同任务同操作焦点。

验证：先编写或运行失败复现，再跑定向 pytest、node:test 和隔离浏览器操作。覆盖慢请求、取消、手动与自动缓存差异、更新时间、焦点和复制。

## 2. 导航和信息密度

- [ ] 手机底栏固定总览、运行任务、TokenHub、队列和更多；更多菜单复用既有链接，关闭/选择/键盘返回焦点正确，桌面仍显示全部页面。
- [ ] 健康连接降低重连权重；顶栏刷新按当前页路由到已有处理器，避免额外全站采集。
- [ ] 总览统计卡转为可访问导航链接；手机压缩统计卡、仓库标题/筛选区；队列增加页内跳转。
- [ ] 存储挂载默认 3 条、可展开，搜索自动展开并复制路径；深色文字使用主题变量。
- [ ] 日志增加浏览器内文本查找及命中定位，显示跟随/暂停状态；历史筛选按站点保存在 sessionStorage。

验证：320/390/768/1440 宽度、两主题、键盘与触控模拟、长字段、弹窗、过滤/分页、前进后退；沿用已有脚本，只修正过期的模拟数据与不确定等待条件。

## 3. 性能与维护

- [ ] 测量 Tabler 实际样式贡献，若可用小型基础规则等价替代，仅去除非终端入口的大样式依赖；否则保留依赖并记录测量结论，不进行无证据的自动裁剪。
- [ ] 镜像搜索对同一数据对象预计算搜索文本和版本字段，合并重复筛选统计，复用现有分页与缓存。
- [ ] 核对未变列表的 DOM 变化、快速切页请求数量与大目录搜索耗时；不宣称未经测量的 CPU 或网络收益。

## 4. 收尾

- [ ] 需求覆盖复核，再进行独立代码质量复核，修复有效发现。
- [ ] 完成相关自动化与浏览器验证、语法、`git diff --check`；用基线清单核实实际修改文件和增量。
- [ ] 输出带完成时间戳的验证报告，说明实际效果及边界。保持 main 和工作区改动，不自动提交、推送或重启运行服务。
