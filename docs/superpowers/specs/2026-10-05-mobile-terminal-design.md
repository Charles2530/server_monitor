# 手机 Terminal：布局、输入与恢复

用户已批准在本机实现、测试并部署紧凑终端方案（2026-10-05）。

## 已复现

模拟手机键盘可视区：844×180 时终端仅 1 行，393×350 时仅 3 行。桌面断点按宽度误覆盖横屏手机，并重新显示提示栏。方向按钮固定发送 CSI，未遵循 application cursor 模式。HTTP 恢复会重新尝试不支持的 WebSocket，并等待无输出长轮询最多 20 秒才恢复输入。输入法候选尚未完成时，快捷 Enter 可能抢先送出。

## 批准设计

连接后手机仅保留一行会话栏（返回、状态、键盘、更多）、可伸缩终端、一行可横向滚动的快捷键。字号、复制、粘贴、连接详情、恢复和断开保留在更多面板；异常原因可展开读取。桌面保留既有工具。按触屏能力及可视区高度识别横屏/键盘，不能只按宽度。横屏 844×180 默认字号至少保留 5 行；393×350 至少 12 行。安全区计入布局；滚动键条不触发按键。

快捷键保留焦点，点击只发一次；方向键跟随 xterm 模式，提供退格和 Ctrl 组合。正在输入法组合时不插入控制字符或抢先执行，提示先确认候选，不自行制造提交或重复文本。错误/断线时禁用发送但允许恢复。不能承诺模拟器涵盖所有 Android 输入法。

兼容连接恢复复用已确定的 HTTP 通道，以即时只读状态恢复 cursor/sequence，不等待下一段输出；旧 read 请求不带新字段仍保持长轮询。鉴权及设备隔离不变；请求结果未知不自动重发，恢复时不新建 Shell。网络不可用期间保留终端内容，重新可用后尝试恢复。

## 验证和部署

Python：即时 read、参数校验、设备隔离、长轮询兼容、重复序号。浏览器：触摸单次输入、组合输入、应用光标、Ctrl、横竖屏/可视区、更多菜单、离线恢复、HTTP 失败及未知输入不重发。真实本地 PTY/tmux 回归，所有云操作模拟。完整 tests 套件和桌面既有 smoke。通过独立代码审查后合并本地 main 并按现有 LaunchDaemon 更新流程部署；保留凭据、数据和配对。不推送 GitHub。
