# SCP 传输进度设计

## 目标

在现有 SSH 文件传输窗口中显示实时进度、已传大小、速度、预计剩余时间和当前文件，继续使用 SCP，不改变现有选择文件、取消、临时目录和原子发布流程。

## 方案

后端为 SCP 子进程开启可解析的进度输出，持续读取 stderr 中的进度行，并把最近一次进度写入内存任务记录。记录包含总字节数、已传字节数、百分比、速度、预计剩余秒数和当前文件名。任务接口继续使用现有轮询接口，前端每秒读取这些字段。

文件传输在启动前已有文件 stat 信息。单文件使用该大小作为总量；目录传输以 SCP 当前文件进度为主，显示当前文件、速度和已用时间，无法可靠汇总时不伪造总百分比。

## 界面

活动任务显示一条进度条；下方显示“已传 / 总量”、速度和预计剩余时间。目录任务额外显示当前文件名。SCP 尚未输出第一条进度时显示“准备传输…”，完成后保留最终统计。

## 验证

增加后端解析测试、任务字段测试和浏览器渲染测试，覆盖未知总量、速度为零、完成状态和移动端无横向溢出。
