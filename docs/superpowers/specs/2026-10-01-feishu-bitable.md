# 飞书监控表

用户已选择持续更新的飞书多维表格，替代复杂消息/日报。数据由本机 Python 同步，不依赖大模型，也不公开本机网站。

- 目标：已创建的「服务器监控看板」，每个站点/任务唯一一行。
- 内容：任务名称、站点、状态、GPU 数量、GPU 利用率、显存占用、集群、类型、采集时间、同步时间、数据状态、官方链接、隐藏的同步标识。
- 直接只读访问 CharlesCloudMonitor 两站点 SQLite 最新快照，仅同步名称含 charles 的个人任务，不同步其他用户排队信息。
- 每 5 分钟同步；字段数值沿用监控面板百分比口径。无效/失败/超过 5 分钟的指标置空，明确标记数据过期。同步时间和采集时间分开。
- 当前快照没有任务时只标记「待确认」，不推断成功、失败或停止。保留此前的记录，避免误删除。
- 新增和更新基于稳定的同步标识，每次写前重新读取记录；创建使用幂等标识，网络失败不连续盲重试创建。
- 飞书应用仅申请所需多维表格能力，只将此监控表授权给应用；密钥保存在仓库外本机 0600 配置。
- 登录/创建凭据/授予应用访问须按电脑操作工具的确认要求完成。现有网站继续本地运行。
- 验收：单元测试、读取实际 SQLite 的 dry run、真实表格写入和二次同步不增行、桌面飞书可见。手机需用户用同一账号打开确认。
