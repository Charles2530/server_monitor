- `server/ide_assets.py`：限定固定版本静态资源的站点隔离磁盘缓存，保留鉴权、压缩变体、容量限制与完整性校验；不缓存文件、HTML、webview 或凭据。

- `server/cci_terminal.py`、`server/terminal_bridge.py`：同一准备流程共享 10 秒内的内部权属校验；普通终端、过期校验与重新登录仍重新检查。保留其他对话的心跳和写锁超时修复。

- `server/ide_proxy.py`：WebSocket 和只读编辑器 HTTP 请求受限恢复；不重放写请求，不拼接既有 WebSocket 字节流；修正压缩 HTML 注入。
- `static/ide.js`、`static/ide-frame-status.js`：工作台可见后才显示就绪；最近单实例选择加速，缓存不无限续期，多实例保持选择流程。
