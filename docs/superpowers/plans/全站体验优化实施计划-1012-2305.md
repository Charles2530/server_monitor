# 全站体验优化实施计划

用户已批准复查报告全部优化，并要求测试后上传 GitHub。沿用当前 main 工作区和既有原生 JS / FastAPI 结构，保留此前改动。任务分批验证后统一提交推送。

## 目标与边界

覆盖五处焦点保持、SSH 检测生命周期和诊断、存储按需挂载、历史曲线保留及大数据绘制、手机首屏与组件反馈。复用现有文件，不改远程终端传输结构，不新增前端框架。保留完整地址复制并增加本机别名指令。图表默认按屏幕保留最小值、最大值和缺口，完整采样入口可还原全部数据。

## 工作分工与验收

- [ ] SSH：server/ssh.py、static/ssh.js，测试 tests/test_ssh.py 和隔离浏览器脚本。缓存新鲜结果，重扫保留已知主机但区分验证状态，隐藏时暂停请求，按主机复用卡片，失败原因仅枚举安全分类。新增别名复制，原地址复制保留。测试重入、隐藏、断网、扫描错误及失败主机。
- [ ] 存储与历史：static/storage.js、static/task-history.js。按记录标识保留操作焦点；挂载前三条初次渲染，展开加载其余内容，筛选可发现所有记录；容量更新保留展开状态和复制反馈。使用前轮 1000 条挂载与焦点诊断，预期初次只创建 3 条。
- [ ] 总览与曲线：static/app.js、static/index.html 和独立纯采样函数。保留总览和手机终端入口焦点；相同任务与范围读取失败保留旧曲线；跨任务隔离；采样保留极值及断点，提供完整模式。测试常量、尖峰、缺口、短数组、时间范围和慢响应。
- [ ] 手机和组件：编辑现有 mobile.css、storage.css、task-history.css、tokenhub.css、workspace.css、navigation.js 和必要 HTML。压缩正常状态、存储汇总和历史统计，ACP 资源输入前置，保留筛选入口；队列计数及区域反馈；TokenHub 低频账号操作菜单。统一忙碌反馈，保留旧主题与六项手机底栏。
- [ ] 验收与发布：运行 node --test tests/*.test.cjs；.venv/bin/python -m pytest tests -q；运行隔离布局、交互、TokenHub、终端及性能脚本。复核变更、修复发现、更新截图及 README 的相关说明，记录验收报告。按文件暂存，不强制添加本地测试或 data，git diff --check 后提交并正常推送 origin/main，读取远端 SHA 确认。

## 测试方式

业务缺陷先用前轮诊断及新增断言复现；先运行失败用例，再实现和回归。视觉修改使用明暗主题和 320 / 390 / 768 / 1440 宽度的截图验证。测试 API 全部模拟，不创建、停止真实云任务或连接远程 Shell。审查代理只读复核，不与实施代理编辑同一文件。
