# 数据传输页面美化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将存储管理中的数据传输页改造成兼顾桌面和手机的紧凑双端工作台，改善长选项、目录浏览、路线提示和空任务状态的视觉层次。

**Architecture:** 保留现有 `storage.js` 的端点选择、目录浏览、提交、轮询和取消逻辑，只通过少量结构类名和 `transfer.css` 完成布局重排与视觉增强。桌面端使用源端/目标端双列，路线与执行方式横跨整行；窄屏自动单列，并保持所有输入控件可触达。

**Tech Stack:** 原生 HTML、CSS、现有 `storage.js` DOM 事件逻辑，Edge 本地浏览器预览。
