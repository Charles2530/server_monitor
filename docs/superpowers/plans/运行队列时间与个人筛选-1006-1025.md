# 运行队列时间与个人筛选

目标：保留所有创建时间、所有用户运行中 ACP 的实时 GPU 升序，将页面标题改成运行队列，展示创建时间和实际运行时长，支持仅查看 charles 的程序。

## 实施范围

1. `server/utilization_queue.py`：只增加展示字段 `created_at`、`started_at`、`duration_seconds`、`is_mine`。时间来自平台 `create_time` 与 `start_time`；运行时长不包含排队时间，缺少或异常启动时间显示未知。复用 `is_charles` 的名称识别规则。列表失败时运行时长停在上次观测时间。
2. `static/index.html`、`static/utilization-queue.js`、`static/utilization-queue.css`：展示运行队列，创建时间与运行时长放在同一列。复选框默认关闭，以已有快照即时筛选，不额外请求云端。筛选后的计数、排序、空状态一致。
3. `tests/test_utilization_queue.py`：先复现字段缺失，再验证创建与启动时间不同、无效启动时间、缓存时长刷新、错误快照时长冻结、名称匹配而非共享账号归属。沿用旧任务与实时排序回归。
