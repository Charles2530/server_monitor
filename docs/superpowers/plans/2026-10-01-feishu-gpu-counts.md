# GPU 卡数量同步扩展

沿用已批准的本机 SQLite → 飞书看板方案，在同一多维表格中增加「GPU 卡数量」数据表。每个非公共集群一行，稳定键为站点和集群 ID。展示可用卡数、总卡数、异常节点卡数、节点数、异常节点数、数据状态和分别对应的采集时间。总量包含异常节点，余量是平台可调度余量；不将两者相减标为已用量。

复用现有认证、字段初始化、幂等新增和记录更新。两表每 60 秒同步一次，独立写入状态；失败或超过 300 秒的数据留空并标记。配置仅保存在本机私有目录。应用继续只访问已有看板。
