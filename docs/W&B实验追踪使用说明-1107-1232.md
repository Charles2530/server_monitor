# W&B 实验追踪使用说明

## 配置

在运行主服务的本机环境中设置：

```bash
export WANDB_BASE_URL=https://api.wandb.ai
export WANDB_API_KEY='重新生成的 W&B API Key'
export WANDB_ENTITY='你的 Entity 或团队'
```

Key 只由服务端读取，不会返回浏览器或手机网关。曾经出现在聊天、截图、终端记录或 Git 历史中的 Key 应立即撤销。

## 页面

打开“实验追踪”，选择项目后查看 Runs。选择 Run 可以读取概览、Summary 指标、配置、History 曲线和最近 Console Logs。Run 详情中的“关联服务器任务”可以把 W&B Run 与当前站点的 CCI / ACP 任务建立关系。

项目和 Run 列表按页读取；History 使用采样数据绘图，Console Logs 默认读取最近 2000 行。W&B 不可用或 Key 失效时，页面保留已缓存数据并显示错误原因。

## 安全边界

W&B API Key 不要写入 `.env` 的版本控制副本、仓库、日志或移动端。自托管 W&B 可以将 `WANDB_BASE_URL` 改为对应的 HTTPS API 地址；服务端仍只接受环境变量配置，不从浏览器接收任意上游地址。
