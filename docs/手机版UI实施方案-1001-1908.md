# 手机版 UI 实施方案

> **For agentic workers:** 使用 subagent-driven-development 执行互不重叠的网页和 Android 工作；最后统一审查与真机验收。

**Goal:** 在手机上完整展示监控信息和常用操作，采用用户已确认的紧凑顶栏、底部六入口、卡片式资源与任务布局。

**Architecture:** 保持现有数据接口及任务操作语义。新增独立手机样式与渐进增强脚本，网页正常加载，同时作为 APK 资产注入受信任的本地监控页面，让已部署的电脑端无需先更新也可适配。Android 只调整连接页、状态栏和监控页返回控件，保留自动登录恢复。

**Tech Stack:** 原生 CSS / JavaScript、现有 Python Playwright 检查、Android Java / Gradle。

## 已确认设计与验收

- 深绿品牌保持一致；手机顶部展示精简品牌和站点切换，底部六入口全部可点击。
- 宽表格按记录显示为带字段标签的卡片，保留提交者、集群、GPU 数、时间与操作。
- 任务名称默认换行，详情可完整阅读；选任务后能直接看到详情并返回列表。
- 日志与命令允许内部滚动，整页不横向溢出；弹窗按钮和输入框不超出视口。
- 连接页把自动恢复状态与主要按钮放在首屏；扫码、手工配对、诊断和更换电脑保持可用。
- 320、393、430 CSS 像素下检查六页面，1440 像素下保持桌面布局；不向真实云任务提交操作。
- APK 覆盖安装保留凭证，真机验证冷启动、导航、任务信息与连接设置。

## 边界

不修改云任务创建、停止、释放重启的后台行为，不执行真实任务操作。样式注入仅作用于本地代理内的监控文档，不作用于 Tailscale 授权网页、官方控制台或 Terminal。字体尊重系统无障碍缩放，采用换行和弹性布局解决拥挤。
