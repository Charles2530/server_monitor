# V1 验收与运行说明

已在当前目录完成并运行 Charles Cloud Monitor V1。地址为 http://127.0.0.1:8766 。

## 实测结果

- 最新联合核验显示 2 个 CCI 应用、3 个 ACP 任务，共配置 58 张 GPU。
- 3 个 ACP 任务都返回两个 worker，每个 worker 的 CPU、GPU、内存、显存均有真实数据；每个 ACP 图表包含 8 条曲线。
- 7 个标准资源池可见。公共池为未知，其余池按实时返回展示 GPU、vCPU、内存。余量变化正常，不在文档中固定该值。
- 默认后台 60 秒轮询，本地网页 10 秒读取快照。用户可关闭网页，采集由独立进程继续。
- 首次引入最近 1 小时的来源指标，此后积累并保留最多 7 天。未声称已积累 7 天。

## 已知边界

电脑休眠、关机或本地进程退出时不会继续采集。过期会话无法自动恢复时，需要点击“连接会话”完成 IAM 登录。内部云接口升级或权限变化可能需要维护。ACP 卡片是 worker 算术平均值，不是不同硬件规格的加权平均。当前不含短信、邮件或任务异常推送；未经过连续 7 天运行验证。
