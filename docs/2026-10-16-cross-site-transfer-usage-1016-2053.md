# 跨站数据传输使用说明

入口是“存储管理 → 数据传输”。选择来源、目标的节点类型、运行节点和文件夹路径，支持浏览远端目录。SenseCore CCI、maoshanwang CCI 来自当前运行任务的可用实例与容器，SSH 节点只列出检测成功的主机。

页面自动规划传输，不需要选择 internal / external。跨站 CCI 目录传输依次执行来源 CCI 的 internal 上传、两个 AOSS endpoint 之间的 external 复制、目标 CCI 的 internal 下载。同站目录省略跨站复制；SSH 节点通过 external 入口访问中转存储。

任务开始前，将运行服务电脑上的 `~/initial/tools/ads-cli.sh` 同步到每个执行节点并 source；本机来源可通过 `MONITOR_ADS_CLI_SOURCE` 指定。远端默认保存为 `~/initial/tools/ads-cli.sh`，可通过远端 `MONITOR_ADS_CLI_SCRIPT` 覆盖。脚本内容不同时先备份旧版，缺少 ads-cli 二进制时调用脚本安装，已有安装则复用。远端需要 Bash、Python 3、可写目录，以及首次安装所需的下载网络。恢复旧脚本时可使用同目录的 `.monitor-backup-*` 备份。

日志记录节点、来源与目标路径、命令、internal / external、阶段耗时、统计和错误。任务列表提供搜索、状态筛选和分页；日志弹窗通过独立接口增量获取最多 2000 条输出，超过上限会提示较早内容已截断。连续进度行合并显示，阅读较早日志时不会强制滚动到底部。日志与任务记录保存在当前服务进程内，重启后不保留。

传输工具报告对象失败或未恢复的错误时，任务会标记失败并停止后续阶段，即使工具退出码为 0。公网入口可达不等于对象允许公网读取；遇到 HTTP 403，需要核查中转桶所属账号、对象读取权限、来源 IP 限制及公网下行额度。自动安装不会修改云端权限。

目标同名文件可能被更新。中转数据使用 `transfer` 桶下的 `.monitor-transfer/<job-id>/` 前缀，完成、失败或取消后均不会自动清理，应按存储策略自行处理。取消会请求停止远端命令，已经传输的文件不会回滚。
