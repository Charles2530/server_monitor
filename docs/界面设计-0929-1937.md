# 监控台界面设计

参考用户提供的 TokenHub 后台截图及 https://tokenhub.ilab.beer/home 。官网 GitHub 链接指向 https://github.com/Wei-Shaw/sub2api 。已查看上游 frontend/src/style.css：白色表面、圆角按钮、青色渐变主按钮、细边框与轻阴影。Firecrawl 未认证，使用浏览器及公开源码核对。

采用白色侧栏和顶栏、低饱和青色背景、18px 卡片圆角、青绿色主按钮与选中态。数字使用等宽数字，增大原页面过小的辅助文字；功能区使用统一线性 SVG 图标。尺寸为本项目适配值，并非参考站的精确测量。

总览保留四张统计卡，加入按 CCI / ACP 汇总的配置 GPU 环图、集群可用 GPU 列表、运行任务速览与快捷入口。只使用现有快照；任务来源失败或配置缺失时展示未知；集群可用数与物理总量不相减。任务速览点击跳到对应监控详情。

五页导航、筛选、历史曲线、创建预览、停止确认与日志流程继续使用现有实现。仅调整前端，不新增依赖。桌面任务列表与图表并排，窄屏纵向排列，表格局部横向滚动。保留键盘焦点与减少动态效果偏好。

验证采用现有导航、ACP、日志与浏览器检查，并补充总览数据、异常状态、任务跳转与 360–1440px 布局测试。保存本地截图。静态文件同步至运行目录前备份，保留实时会话和数据库。
