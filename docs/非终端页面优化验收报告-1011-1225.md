| TokenHub | 新日期查询替换旧请求，隔离迟到响应；Key 按 ID 更新，保留焦点和复制状态。趋势、小时费用和列表采用每类最近一次结果的 60 秒缓存，手动刷新、账号及分组变化正确失效。可见时通过 RAF 合并图表 resize；慢图库加载过程中切页返回会补绘。 |
| 后端刷新 | 历史、存储、利用率接口接收 `refresh=true`，绕过正常 TTL 和失败重试等待，同时保留进行中请求合并及后台读取。 |
