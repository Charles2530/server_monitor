# 网站读取与交互优化报告

本轮继续优化日志、历史图表、集群规格及节点分配读取。代码与发布候选已通过验证，本文生成时运行服务尚未切换。发布包包含此前尚未部署的全站、Terminal 与 VS Code 优化。

## 原因与修改

| 功能 | 已确认开销 | 修改与验证 |
| --- | --- | --- |
| 日志自动刷新 | 相同快照仍重写文本并滚动，反复重选当前标签会取消请求并重新读取 | 仅在可见日志变化时写入和跟随滚动；重选当前标签直接返回。三次相同 1 MiB 快照的额外文本赋值从 3 次降为 0，四次重选额外请求从 4 次降为 0。 |
| 多 Worker 历史图表 | 每条曲线重新扫描名称和之前的曲线，准备工作随曲线数平方增长 | 用 Map 顺序计数，保留标签消歧、颜色、线型和数据顺序。400 条曲线夹具的指标属性读取从 163,000 次降为 4,200 次。 |
| 图表窗口缩放 | 每次 resize 都立即重建图表 | 同一动画帧合并重绘，使用回调执行时的当前任务。100 次同帧 resize 从 100 次重绘降为 1 次。 |
| 集群规格读取 | 独立集群的 resourceSpecs 串行等待 | 先验证绑定及挂载兼容，再最多 3 路并发读取，按输入优先级输出。 |
| 节点分配读取 | 每批 20 个节点的 observe 请求串行等待 | 每批仍最多 20 个节点，最多 3 路并发，保留 8 秒整体期限。 |

后端使用固定每请求等待 20ms 的合成夹具，各运行 7 次。3 集群规格读取中位数为 63.28 → 21.50ms；60 节点分配读取为 63.83 → 22.14ms。这些数值说明独立等待能够重叠，不代表生产网络速度或整个页面的加速比例。前端计数来自隔离行为测试，本轮未进行生产页面端到端测速。

## 正确性边界

- 日志每次真正刷新仍请求服务器；时间、告警及权限失效提示照常更新，不增加权限缓存。
- 切换任务、Worker、容器、标签或隐藏页面时，旧请求仍取消，迟到响应不覆盖当前内容。
- 集群绑定、站点隔离、VPC 与挂载检查保留；并发任务失败或取消时，先取消并等待其余任务退出，再返回调用方。
- 节点数据继续校验完整 UID 集合、数量及分页状态；任一批失败时整组显示未知，不推断为空闲。
- 未修改创建、停止或释放云任务的动作。
