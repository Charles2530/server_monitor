# V2 设计与实施计划

目标：为本机网站加入 ACP 创建、停止及等待启动列表，保留 CCI 和运行任务监控。用户已授权按此前验证流程实现并部署。

## 界面与边界

- 创建表单仅四项：显示名称、副本数、每副本容器 GPU 数、启动命令。总 GPU 自动计算；集群自动按 modeltoolchain-test、modeltoolchain、vigen 顺序选择。容器的实际 CPU、内存随集群标准规格确定，并在提交前预览。
- 不显示镜像、挂载、环境变量、框架、优先级等可编辑项；复制最新创建、显示名称包含 charles 的 ACP 任务（含已停止任务）。命令空白用 sleep inf，否则用户命令末尾另起一行追加 sleep inf。
- 表单先预览，显示模板 ID、目标集群、实际资源总量、排队提示及最终命令，再确认创建。按钮防重入；后端写入不自动重试，持久化操作 ID 防止超时或重复点击重复创建。
- 停止入口仅对 charles 的可停止 ACP 任务提供；弹窗显示名称和 ID，后端再次获取任务并核对名称及状态，不提供删除、CCI 停止或自动重启。
- 等待列表独立展示 ACP 等待配额、排队、创建、启动、重启、恢复中任务和停止中的进度，不请求监控曲线。显示平台状态，不笼统声称所有启动任务都缺卡。列表失败保留旧快照与旧时间并标记。

## 实施顺序

1. 从控制台前端及只读 API 核实 trainingJobs POST、trainingJobs/{name}:stop POST、资源规格及状态枚举。创建启用 enable_queuing=true。原采集器的重试函数只用于读请求。
2. 在 tests/test_acp_actions.py 写创建参数、模板选择、集群优先级/不足排队、继承字段、命令替换、目标限定及超时去重测试；运行失败后实现 server/acp_actions.py、操作记录存储与 API。
3. 在 tests/test_collector.py 验证等待任务无指标请求、已停止排除、状态转换、列表失败回退；实现 waiting_tasks 采集及白名单字段输出。
4. 按固定 API 契约实现 static/acp.js、表单、确认框、ACP 停止入口及等待表；同步 V2 标识和只读文案。前端验证使用本地模拟 API，不停止真实训练任务。
5. 独立复核功能范围与代码质量，运行完整测试、浏览器验收和真实只读预览验证。更新 README 与验收文档。
6. 备份运行代码并部署 LaunchAgent，保留本机会话和历史。验证真实任务、等待列表与资源数据。若进行真实写入验收，仅使用明确标识的单卡测试任务并在验证后停止，不触碰现有训练任务。

## API 契约

- GET /api/acp/options → template {id,name,created_at}、gpu_options（整数数组）、default_gpus_per_replica、cluster_order、updated_at。
- POST /api/acp/preview ← {display_name,replicas,gpus_per_replica,command} → preview_id、expires_at、template、cluster {id,name}、replicas、gpus_per_replica、total_gpus、vcpu_per_replica、memory_gib_per_replica、command、will_queue、message。
- POST /api/acp/create ← {preview_id} → {id,name,state,message}。使用服务器保存的预览配置，不接受前端任意云端 payload。
- POST /api/acp/stop ← {task_id,display_name,request_id} → {id,name,state,message}。
- GET /api/state 新增 waiting_tasks，运行任务仍在 tasks。等待条目含 id、kind、name、cluster、state、state_label、gpu_count、replicas、created_at、observed_at、can_stop；不含脚本、环境变量、令牌和原始响应。
- 操作失败统一返回 {error,code}，不返回云端原始正文。创建结果不明时保留操作记录，要求核对任务，禁止自动重发。

## 验证重点

必须覆盖集群 GPU 足够但 CPU/内存不足、命令空白、非法节点数、跨工作空间/CCI/他人任务拒绝、模板变化、同一预览并发重复提交、提交超时、等待转运行后正常采集、页面失败提示、390px 布局。排队原因只以平台已知状态表述。
