# TokenHub 复制密钥

已在 API 密钥列表的每条名称旁增加“复制密钥”，按点击获取当前密钥完整值并复制到剪贴板。未改变现有密钥、分组、用量或花费图功能。

## 实现

- server/tokenhub.py、server/tokenhub_routes.py：新增显式 POST /api/tokenhub/key-copy，严格校验 key_id/account_id，核对远端账号、密钥归属及会话代次。上游仅 GET，无密钥修改；列表及快照仍不含明文；响应 no-store。
- static/tokenhub.js、static/index.html、static/tokenhub.css、static/appearance.css：复制按钮、成功/失败反馈，剪贴板受限时支持再次点击；旧环境使用临时隐藏文本框并立即移除。待复制内存保留不超过30秒，导航、隐藏、列表刷新及断开时清理。
- server/mobile_gateway.py：精确允许复制 POST，要求设备控制权限；不扩大只读设备能力，无需更新APK。
- tests/test_tokenhub.py、tests/test_tokenhub_api.py、tests/test_mobile_gateway.py、scripts/tokenhub_smoke.py：增加归属/会话隔离、POST及缓存策略、移动权限、剪贴板重试/备用路径/导航取消验证；README更新使用说明。
