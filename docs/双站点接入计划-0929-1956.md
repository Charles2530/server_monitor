# 双站点接入计划

目标：左下角左右切换 maoshanwang 与 sensecore，使用相同功能与 charles 过滤规则。

实现采用站点配置对象与独立运行上下文。每站拥有独立登录会话、采集器、SQLite 历史及 ACP 操作记录。默认 maoshanwang 保留原数据路径；SenseCore 放入 data/sensecore。请求携带白名单站点标识，未知标识拒绝。浏览器切换使用完整页面导航，避免旧请求回写新站点；待核对操作记录按站点隔离，云写入期间禁用切换。

1. 验证 SenseCore IAM 登录，确认 ModelToolChain 工作空间、CCI/ACP、配额、监控及日志接口。
2. 配置注入 auth、collector、inventory、ACPManager、TaskLogs，默认参数兼容原站点和测试。
3. API 为两个站点分别创建服务；所有读写、历史与刷新通过站点选择，不修改全局当前站点。
4. 新增 sites.js/sites.css，仅提供必要切换行为。现有请求函数增加站点头，ACP 恢复记录分离。保留另一聊天的主题美化。
5. 补充多站隔离测试，运行原有后端和前端检查。真实验证只进行读取和创建预览，不创建或停止实际任务。
6. 备份运行代码，部署并核对两站状态、资源、模板与切换。自动登录和数据库继续由现有 LaunchAgent 管理。
