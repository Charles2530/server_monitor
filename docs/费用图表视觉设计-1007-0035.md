# 费用图表视觉设计

只调整 TokenHub 两张费用图，保留既有页面布局、额度卡片、接口与费用口径。

参考 https://tokenhub.ilab.beer/ 的公开页面、用户提供的原站图表截图，以及原站公开 TokenUsageTrend 前端模块。公开模块采用蓝色 #3b82f6、青色 #06b6d4、0.3 曲线张力、低透明度填充和主题适配。首页 branding 提取置信度低，不用于推断登录后页面排版。

采用蓝色每日曲线、青色逐小时曲线，使用保形的轻微平滑、仅悬浮显示节点、淡色面积和简洁横轴。去掉两张图内金额区域的嵌套灰色边框，保留完整金额、小数、峰值、时间范围和更新状态。深色沿用当前页面背景与文本，仅适配图表强调色。

原始数据不修改；无使用小时仍为零，接口错误保留旧结果。验证图表数据和提示精度、主题切换、320–1440 像素宽度、固定高度和线上资源一致性。
