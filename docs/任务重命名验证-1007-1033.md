# 云任务重命名

2026-10-07，已更新本机主站与移动网关。

任务资源监控标题右侧新增铅笔按钮。点击后编辑完整显示名称，支持保存、取消和键盘操作；明确提示保留 charles，前后端均校验名称。适用于两个站点的本人 CCI/ACP 任务。

服务端核对当前工作空间、本人任务列表及原名称，仅 PATCH display_name，然后读回云端名称。保留任务 ID、运行状态、启动配置和历史曲线。操作记录防止重复写入；超时后使用 check_only 只读核对，刷新页面可恢复原请求。未提交的请求返回明确状态，让用户重新保存。

名称更改后保留所选任务；若原搜索词不再匹配，清空搜索以继续展示当前任务。任务与队列分别等待成功的新采样后结束临时名称显示，避免旧快照、局部读取失败或后来云端再次改名导致错误覆盖。
