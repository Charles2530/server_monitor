# 手机客户端与 Mac 网关实施计划

**Goal:** 在另一个常开 Mac 上运行现有监控后台，Android APK 内嵌 Tailscale 用户态连接，经配对网关访问现有界面和 API。

**Architecture:** 保持监控 127.0.0.1:8766 不变。新增 127.0.0.1:8767 网关，由目标 Mac 的 Tailscale Serve 提供私网 HTTPS。Android 使用 tsnet、进程内 HTTP 转发和 WebView，不注册系统 VpnService。必须通过真机移动网络验证后才能认定跨网可用。

**Tech Stack:** Python/FastAPI/httpx/SQLite；Go tsnet + gomobile；Android Java/WebView/Keystore；Gradle。

## 1. 电脑网关

新增 server/mobile_access.py（配对票据、设备审批、撤销）、server/mobile_gateway.py（白名单转发）、server/mobile_admin.py（本机管理）。单独设备数据库，不修改任务数据库。

- 先补 tests/test_mobile_access.py，运行 `.venv/bin/python -m pytest tests/test_mobile_access.py -q`，确认缺失功能失败。
- 配对二维码/JSON 只有 HTTPS 网关地址和 5 分钟一次性随机票据，不携带云 IAM 密码或 Tailscale 长期密钥。
- 手机兑换票据后得到独立设备 token，默认待审批。本机批准后才允许读接口；写权限另行批准。
- 持久化只保存 token 哈希；手机未批准、已撤销、过期均不能读业务数据。一次性兑换在 SQLite 事务内完成。
- 网关不透传浏览器 Cookie、Host、Origin、Authorization；只给固定 loopback 后端发送受控请求。所有业务路径与方法显式列举，禁止通用 URL 代理。
- 写请求只发送一次，转发失败给出“结果未知，核对任务后重试”，沿用后台原有去重语义。
- 测试跨站点、未授权、读权限拒写、路径穿越、配对重放、并发兑换、撤销和错误脱敏。

## 2. 内嵌连接模块

新增 mobile/tunnel（Go 模块，固定 Tailscale 版本及 go.sum）。使用 tsnet 的 Start、LocalClient、Status、StartLoginInteractive 和 HTTPClient。

- 先写 Go 测试，覆盖网关 URL、跳转限制、本地 WebView 会话、代理请求和不自动重试写操作。
- 网络认证使用官方授权页面，身份保存在 App 私有目录。不能把长期 auth key 写进 APK。
- Go 只连接用户配对的 *.ts.net HTTPS 网关；HTTP 重定向禁止自动跟随。
- 只监听手机 127.0.0.1 随机端口；WebView 启动票据一次性兑换 HttpOnly Cookie；其他本地进程不能仅凭端口读取云数据。
- 浏览器请求中的 Authorization 被丢弃，由原生模块加入设备凭证；token 不注入网页 JavaScript。
- 网关错误、电脑离线和设备待审批分别返回，不将旧数据伪装成实时数据。

## 3. Android APK

新增 mobile/android，Java Activity + Go AAR，ARM64 优先；不复制云 IAM 密码。

- 首页包含网络状态、首次 Tailscale 登录、二维码扫描/粘贴配对内容、设备审批状态、进入监控、更换电脑。
- Android Keystore 加密设备凭证；备份关闭；WebView 禁止任意文件访问和 JavaScript 原生桥。
- WebView 仅允许本机转发源。官方任务/Terminal 交给系统浏览器；第一次官方登录由手机完成，不假定继承电脑会话。
- 对 target=_blank 和 Terminal launcher 保留导航支持；更换主机时销毁旧 WebView、停止旧代理并清理旧 Web 存储，避免站点/操作状态串用。
- Android 构建脚本固定 Go、gomobile、Gradle、AGP 等版本。缺工具时列出可执行的准备命令，不假称已构建。

## 4. 目标 Mac 与 AI 交接

- 新增网关 LaunchAgent 管理脚本，默认回环监听，无公网端口，无 Tailscale Funnel。
- 配对/批准/撤销均使用本机 CLI；Serve 配置由目标机器的登录身份和真实主机名生成。
- 写面向目标 AI 的部署文档：先验收 8766，再启动 8767，再登录 Tailscale/配置 Serve，最后手机入网配对。
- 首轮只批准读权限。未经用户当次明确要求，不创建、停止、重启真实云任务。
- 明确登录后启动与开机未登录的区别；禁止自动修改休眠和 FileVault 设置。

## 5. 验证与交付

- Python 全量测试、Go 单元/竞争测试、格式检查。
- 尽可能构建 Android APK；未完成的 SDK/NDK/真机条件按实际结果记录。
- 独立测试端口验证网关启动，不重启现有监控服务。
- 真机验收：手机关 Wi-Fi 用流量，配对审批、读两站点、换网恢复、设备撤销、电脑离线、回到前台刷新。
- 交付源码、构建/部署命令、已通过检查及未验证清单；不把编译通过等同于真机跨网通过。
